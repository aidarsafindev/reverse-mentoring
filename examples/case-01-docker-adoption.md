# Кейс 1: Внедрение Docker по инициативе джуна

## Контекст

**Команда:** 20 разработчиков 1С
**Проблема:** тестовые среды разворачиваются вручную
**Время развёртывания:** 4 часа
**Конфликты:** тестовые среды часто конфликтуют между собой

**Тимлид (15 лет опыта):**
«Так всегда делали. Работает же.»

## Обратное менторство

**Джун (3 месяца в компании)** на reverse mentoring сессии показал Docker.

**Диалог:**

Тимлид: «И что, 1С можно в контейнере запустить?»

Джун: «Да. Вот смотрите: `docker-compose up` — и через 3 минуты
у вас PostgreSQL, платформа 1С и тестовая база готовы.»

## Демонстрация

**До Docker:**

```
1. Установить PostgreSQL (30 мин)
2. Создать базу (15 мин)
3. Установить платформу 1С (45 мин)
4. Создать информационную базу (30 мин)
5. Загрузить дамп (60 мин)
6. Настроить подключения (30 мин)
7. Проверить что всё работает (30 мин)

Итого: 4 часа
```

**С Docker:**

```yaml
# docker-compose.yml
services:
  postgres:
    image: postgres:16
  one-c:
    image: 1c-platform:8.3
```

```bash
docker-compose up -d
```

**Итого: 3 минуты.**

## Результат

| Метрика | До | После |
|---------|----|----|
| Время развёртывания | 4 часа | 3 минуты |
| Конфликты сред | 3-4 в месяц | 0 |
| Параллельные версии 1С | Нет | Да |
| Экономия на разработчика | — | 15 часов/мес |

**Экономия на команду:** 15 часов × 20 разработчиков = 300 часов/мес

## Цитата тимлида через 3 месяца

«Я 15 лет разворачивал тестовые среды вручную. Думал это норма.
Оказалось — можно за 3 минуты. Спасибо Антону что открыл глаза.»

## Что было дальше

1. Docker внедрён для всех тестовых сред
2. Настроен CI/CD на базе Docker
3. Разработана внутренняя платформа для быстрого создания сред
4. Антон получил повышение — Middle через 8 месяцев вместо 18

# Шаблон сессии обратного менторства

## Метаданные

- **Дата:** [дата]
- **Джун-ментор:** [Имя]
- **Тимлид-ученик:** [Имя]
- **Тема:** [конкретная технология / инструмент / подход]
- **Длительность:** 30 минут

## Цель сессии

После сессии тимлид сможет: [конкретное действие]

Примеры:
- «Запустить Docker-контейнер с PostgreSQL»
- «Настроить AI-ассистента для проверки кода»
- «Понять как работает gRPC и зачем он нужен»

## План сессии (30 минут)

### 1. Контекст (5 минут)

- [ ] Какую проблему решает эта технология?
- [ ] Почему это может быть полезно для нашей команды?
- [ ] Где это уже используют?

### 2. Демонстрация (15 минут)

- [ ] Живая демонстрация (терминал, IDE, веб-интерфейс)
- [ ] Минимальный работающий пример
- [ ] Не слайды — код!

### 3. Практика (5 минут)

- [ ] Тимлид пробует сам под руководством джуна
- [ ] Одна простая операция: запустить, написать запрос, развернуть

### 4. Обсуждение (5 минут)

- [ ] Применимо ли это у нас?
- [ ] Какие есть препятствия?
- [ ] Что нужно чтобы попробовать на проекте?

## Результат

- [ ] Тимлид понял суть технологии
- [ ] Тимлид попробовал сам
- [ ] Принято решение: пробуем / откладываем / не подходит
- [ ] Если пробуем — кто и когда сделает пилот?

## Пример заполненной сессии

**Дата:** 15.03.2026
**Джун-ментор:** Антон
**Тимлид-ученик:** Дмитрий
**Тема:** Docker для тестовых сред

### Контекст

Антон: «У нас развёртывание тестовой среды занимает 4 часа.
Docker позволяет упаковать всё окружение в контейнер и запускать
одной командой за 3 минуты.»

### Демонстрация

```bash
docker-compose up -d
```

Показал: через 3 минуты всё готово. Проверили подключение.

### Практика

Дмитрий сам запустил `docker-compose up -d`, остановил `docker-compose down`,
зашёл внутрь контейнера через `docker exec -it`. Успешно.

### Обсуждение

- Применимо: да, для всех тестовых сред
- Препятствия: нужно обучить команду, обновить CI/CD
- Пилот: Дмитрий берёт на себя, срок — 2 недели

### Результат

- Решение: пробуем
- Пилот назначен: Дмитрий, срок 2 недели
- Публичное упоминание в канале #dev-team

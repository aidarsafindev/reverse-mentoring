# Темы для джунов-менторов

Список тем которые джуны могут показать тимлидам. Обновляется по мере
появления новых технологий.

## Новые технологии

- **Docker и контейнеризация** — упаковка окружения в контейнеры
- **Kubernetes** — оркестрация контейнеров для тестовых сред
- **gRPC и Protocol Buffers** — когда REST недостаточно
- **GraphQL** — гибкие запросы к API
- **WebAssembly** — выполнение кода в браузере
- **eBPF** — диагностика на уровне ядра Linux

## Инструменты разработки

- **AI-ассистенты** — GitHub Copilot, Cursor, Codeium для 1С-разработки
- **Современные IDE** — VS Code с плагинами для 1С, альтернативы EDT
- **No-code/Low-code платформы** — когда и зачем
- **Современные терминалы** — Warp, Fig, Oh My Zsh
- **Postman и аналоги** — автоматизация тестирования API

## DevOps и инфраструктура

- **CI/CD нового поколения** — Dagger, Earthly, Nix
- **GitOps** — ArgoCD, Flux
- **Infrastructure as Code** — Terraform, Pulumi, Ansible
- **Observability** — OpenTelemetry, Grafana, Prometheus
- **Мониторинг** — Sentry, Datadog, Grafana

## Базы данных

- **Новые СУБД** — ClickHouse, CockroachDB, YugabyteDB
- **Графовые базы** — Neo4j, Dgraph
- **Time-series базы** — InfluxDB, TimescaleDB
- **Векторные базы** — Pinecone, Weaviate, Qdrant (для AI)
- **Кэши** — Redis, Hazelcast, Memcached

## AI и машинное обучение

- **LLM для кода** — как использовать ChatGPT/Claude/GigaChat для 1С
- **RAG** — retrieval-augmented generation для документации
- **MCP-серверы** — интеграция AI с 1С
- **AI-агенты** — автономные помощники для разработки
- **Промпт-инжиниринг** — как правильно формулировать задачи

## Источники знаний

- **Технические блоги** — Hacker News, Dev.to, Habr
- **YouTube-каналы** — по DevOps, архитектуре, базам данных
- **Open-source проекты** — что можно переиспользовать
- **Сообщества** — Discord, Telegram-каналы, Reddit

## Как выбирать тему

1. **Интерес тимлида** — спросите что ему было бы интересно
2. **Применимость** — тема должна решать реальную проблему команды
3. **Простота** — джун должен сам уверенно владеть темой
4. **Практика** — должна быть возможность попробовать руками

## Как обновлять список

- Раз в месяц джуны добавляют новые темы
- Раз в квартал тимлиды отмечают что уже освоено
- Устаревшие темы переносятся в архив

# Reverse Mentoring: чему джуны могут научить тимлида

> Менторство наоборот — когда джун учит тимлида новым технологиям,
> инструментам и подходам. 30 минут в неделю. Источник инноваций.

Репозиторий с шаблонами, чек-листами, кейсами и скриптами для внедрения
обратного менторства в команде разработки 1С.

## Что внутри

- **Шаблон сессии** — структура на 30 минут: контекст, демонстрация, практика, обсуждение
- **Список тем для джунов-менторов** — новые технологии, инструменты, подходы
- **Чек-лист тимлида-ученика** — что делать до, во время и после сессии
- **Три реальных кейса** — Docker, AI-ассистент, CI/CD
- **Планировщик сессий** — генератор расписания на месяц с ротацией пар
- **Трекер метрик** — учёт сессий, идей, внедрений, экономии

## Быстрый старт

```bash
git clone https://github.com/yourname/reverse-mentoring-demo.git
cd reverse-mentoring-demo

# Сгенерировать расписание на месяц
python3 scripts/session-scheduler.py

# Посмотреть шаблон сессии
cat templates/reverse-mentoring-session.md

# Изучить кейсы
cat examples/case-01-docker-adoption.md
cat examples/case-02-ai-code-review.md
cat examples/case-03-ci-cd-optimization.md
```

## Три реальных кейса

### Кейс 1: Docker

**Проблема:** тестовые среды разворачиваются 4 часа, конфликтуют между собой.

**Решение:** джун показал Docker. Время развёртывания — 3 минуты. Экономия 300 часов/мес.

### Кейс 2: AI-ассистент для код-ревью

**Проблема:** сеньор тратит 15 часов в неделю на проверку очевидных вещей.

**Решение:** джун показал AI-ассистента. Время код-ревью -40%, баги -30%.

### Кейс 3: Оптимизация CI/CD

**Проблема:** сборка занимает 2 часа.

**Решение:** джун задал вопрос «почему так долго». Сборка — 10 минут, в 12 раз быстрее.

## Метрики успеха

| Метрика | Через 6 месяцев |
|---------|-----------------|
| Проведено сессий | 24 |
| Предложено идей | 12 |
| Внедрено идей | 5 |
| Экономия времени | 400 часов/мес |
| Удовлетворённость тимлидов | 4.5/5 |
| Удовлетворённость джунов | 4.8/5 |

## Ключевые принципы

1. **30 минут в неделю** — не больше. Формат: 5 мин контекст, 15 мин демонстрация, 5 мин практика, 5 мин обсуждение.
2. **Тимлид пробует руками** — не слушает лекцию, а делает сам под руководством джуна.
3. **Публичное признание** — «Эту идею предложил Антон на reverse mentoring сессии».
4. **Живой список тем** — технологии появляются каждый месяц, список обновляется.
5. **Разделение зон экспертизы** — джун знает новые технологии, тимлид знает архитектуру и предметную область.

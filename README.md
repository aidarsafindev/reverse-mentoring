# Reverse Mentoring: чему джуны могут научить тимлида

> Менторство наоборот — когда джун учит тимлида новым технологиям,
> инструментам и подходам. 30 минут в неделю. Источник инноваций.

Репозиторий с шаблонами, чек-листами, кейсами и скриптами для внедрения
обратного менторства в команде разработки 1С.

---

## Что внутри

- **Шаблон сессии** — структура на 30 минут: контекст, демонстрация, практика, обсуждение
- **Список тем для джунов-менторов** — новые технологии, инструменты, подходы
- **Чек-лист тимлида-ученика** — что делать до, во время и после сессии
- **Три реальных кейса** — Docker, AI-ассистент, CI/CD
- **Планировщик сессий** — генератор расписания на месяц с ротацией пар
- **Трекер метрик** — учёт сессий, идей, внедрений, экономии

---

## Быстрый старт

```bash
git clone https://github.com/yourname/reverse-mentoring-demo.git
cd reverse-mentoring-demo

# Сгенерировать расписание на месяц
python3 scripts/session-scheduler.py

# Посмотреть шаблон сессии
cat templates/reverse-mentoring-session.md

# Изучить кейсы
cat examples/case-01-docker-adoption.md
cat examples/case-02-ai-code-review.md
cat examples/case-03-ci-cd-optimization.md
